# Food Website

A responsive, single-page food and restaurant landing page with sections for the menu, popular dishes, how it works, reviews and contact.

Built by following a "complete responsive food website design" tutorial, as HTML/CSS/JavaScript practice.

## Features
- Responsive layout for mobile, tablet and desktop
- Sticky header with mobile menu toggle (`script.js`)
- Menu, dishes, steps, reviews and contact sections

## Tech stack
HTML5 · CSS3 · JavaScript

## Run
Open `index.html` in a browser. No build step needed.
